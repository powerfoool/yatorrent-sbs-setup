# Внешний AIM2-профиль

Публичный навык не содержит .aim2, broker credentials, Codex auth или частных архивов предыдущих релизов. Владелец экспортирует AIM2 из YaTorrent и передаёт файл напрямую на целевой Mac защищённым каналом. Не загружай его в SkillStore, GitHub, каталог навыка или prompt.

Размести файл в отдельном приватном каталоге вне навыка, выставь права 0600. Установщик принимает только принадлежащий текущему пользователю обычный файл, без симлинков, размером не более 1 MiB, AIM2 version=1 с broker и Codex model. Не исправляй credentials автоматически. `--plan` допустим без профиля; `--apply` без `--profile` останавливается до загрузок и изменений.

Пример установки из каталога распакованного навыка:
```sh
python3 scripts/install.py --plan --profile /absolute/private/profile.aim2
python3 scripts/install.py --apply --profile /absolute/private/profile.aim2
```
Путь профиля может содержать пробелы при корректном shell quoting. Это не команда запуска Chromium: постоянные browser/reader entry points имеют отдельное обязательное требование безопасных путей без кавычек.

Установщик копирует байты в приватный root/profiles/databroker.aim2 (0600), фиксирует SHA-256, затем штатное приложение импортирует файл через safeStorage. Полная verify сравнивает приватную копию с installation marker и квитанцией зашифрованного импорта. Для дополнительного сравнения с исходником передай `verify.py --profile PATH`; без этого параметра проверяется установленная приватная копия. При обновлении профиля повтори установку с новым внешним файлом при остановленном worker.

Публичные поля могут включать адрес инфраструктуры и модель; они не являются разрешением публиковать весь профиль. Используй отдельные credentials worker с минимальными необходимыми правами. Для нового Mac Codex авторизуется штатным входом владельца, auth.json другого компьютера не переносится.
