# Команда для бригадира и разведчиков

Используй готовую **browser_command_string** из успешной полной verify целевой установки. Executable и browser script должны иметь безопасные абсолютные пути и передаваться **без кавычек**. Не применяй shlex.quote/shlex.join, не оборачивай команду в дополнительный shell. Для старого пути с пробелами требуется новая безопасная установка, а не добавление кавычек.

1. Запусти `NODE BROWSER_SCRIPT --server --android` через обычный exec_command с yield1000. Для desktop не передавай `--android`; оконный повтор — `--headed` при доступной GUI-сессии.
2. В ready возьми browser session `sbs-chromium-XXXXXX`. Это **не** exec session_id. Для команды без кавычек используй `NODE BROWSER_SCRIPT --send64 SESSION BASE64URL`, где BASE64URL — UTF-8 JSON операции, закодированный base64url без padding. Токен содержит только буквы, цифры, `_` и `-`; никаких shell-кавычек и подстановок. Например `{"op":"observe"}` → `eyJvcCI6Im9ic2VydmUifQ`; `{"op":"close"}` → `eyJvcCI6ImNsb3NlIn0`. Декодирование допускает только JSON фиксированных операций, не JS. Старый argv-режим --send сохранён для программных клиентов. Не вызывай write_stdin для управления сервером.
3. Открой назначенный URL: `{"op":"goto","url":"https://..."}`. При timeout проверь `observe`: могла загрузиться полезная часть страницы. При необходимости дождись содержимого и просмотри снимок карты/интерфейса.
4. Закрой свой браузер: `{"op":"close"}`. После пяти минут без действий сервер также закрывается автоматически.

Операции: `observe`, `inspect` (CSS), `click` (selector), `click_xy` (x,y), `drag` (fromX,fromY,toX,toY), `scroll` (x,y), `fill` (selector,value), `press` (selector,key), `wait` (ms≤10000), `screenshot` (path,fullPage), `close`. Произвольных evaluate, JS, shell, upload и чтения локальных файлов нет. Снимок ограничен текущим workspace и нужен только для наблюдения; обязательного сохранения снимков/логов/оценок у разведчика нет.

При разрешённой CAPTCHA используй свежий inspect/снимок и click/drag, фиксируй число действий и реальный исход. Не считай исчезновение iframe успехом без доступа к странице. Не запрашивай повторно уже данное согласие для того же запуска; соблюдай ограничения среды.

Возвращай отчёт сообщением с requested_url, observed_url, реально полученным содержимым, действиями, доступными фактами и неизвестным. HTTP200/canvas/текст карточки сами не подтверждают работающую карту. Бригадир получает оценки от разведчика, проверяет их и сравнивает SERP.
