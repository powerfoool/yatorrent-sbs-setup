# YaTorrent SBS setup — r9

Публичный навык для macOS Apple Silicon: нативный YaTorrent с executor-runtime.json и sbs-codex-v1, Codex/Chromium, 11 агентов на пару, 4 параллельных задания и 1800с. Целевой официальный latest stable — [YaTorrent0.3.10](https://github.com/RudenkoAD/YaTorrent-releases/releases/tag/yatorrent-v0.3.10). Совместимость его нативного контракта подтверждена проверкой официального DMG/SHA256, подписи приложения и точных ASAR/worker ресурсов; это не заменяет полную verify фактической установки. Codex CLI закреплён на 0.162.1. Приложение не патчится и не переподписывается.

Worker исполняет разметку; координатор читает исходную таблицу, локально разбирает органический top-5 каждой стороны и передаёт только URL с позициями, запрос и его контекст. HTML, titles, snippets, изображения и source SERP URL не попадают к исполнителям. Порядок и дубли сохраняются; бригадир назначает одного разведчика на каждый точный URL. Оцениваются ранжирование top-5 и посещённые страницы. В восьмиполевом итоговом JSON сохраняется extra_blocks с выводом о недоступности и score=null, поскольку визуальная SERP не передана. Резерв только по URL не подтверждает сниппеты или качество страницы.

Пакет содержит публичные prompts/foreman.md и prompts/scout.md. Только координатор читает их и передаёт полные роли в input_data с контрактом sbs-instructions-v2 и маркером SBS_COORDINATOR_TASK_V2; launcher применяет их до модели. Новый выбор — только по фактической команде пользователя, сохранённой в receipt. Result pool по умолчанию kron; пользователь выбирает удобный результат и место записи, технические детали настраивает координатор. По умолчанию его машина также выполняет задачи. [SKILL.md](SKILL.md), [координатор](references/coordinator.md), [внешний профиль](references/profile.md).

Credentials не включены. AIM2 и OAuth-клиент передаются отдельными приватными файлами, авторизация происходит на целевой машине; путей машины автора и зависимости от его memory bank нет. Установка запускается только по поручению настроить эту машину. Полная verify без skip и реальный Codex/Chromium обязательны; тесты сборки не заменяют clean-Mac установку, broker end-to-end или readback выбранной таблицы.

Сборка: scripts/build-release.py --output /path/outside-skill/release.zip; явная инвентаризация, MANIFEST и SHA256, запрет secrets/авторских путей. Для релиза требуется независимое ревью и закрытие всех blockers/major. Текущий канал поставки — локальный ZIP и GitHub; публикация в SkillStore отложена и требует отдельного поручения.
